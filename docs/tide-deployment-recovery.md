# 게임 배포 복구

2026-09-13

이전에 별도로 배포한 게임 파일이 Git 저장소에 포함되지 않았다. 이후 울릉고 수업 자료를 Git에서 배포하면서 `/games/tide-room`과 `/play/tide-room`이 빠졌다. 공개 게임 주소가 404를 반환하는 것을 확인했다.

현재 운영 소스에 게임 코드·이미지·음악과 홈 및 미니 프로젝트의 진입 카드를 추가했다. 수업 자료 경로와 번역은 유지했다. 작업 중인 말하기 기능과 환경변수 파일은 포함하지 않았다.

이후에는 저장소의 최신 main을 기준으로 배포한다. 배포 전에 `npm run test:tide`와 `npm run build`를 실행하고, 배포 뒤 `node scripts/check-tide-http.mjs https://dullg-landing-one.vercel.app`로 게임 페이지와 미디어 응답을 확인한다. 이 검사는 브라우저 조작이나 실제 청취를 대신하지 않는다.
