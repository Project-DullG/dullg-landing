# 9월 19일 울릉고 방문 특강

- 사용자 확인: 2026년 9월 19일 토요일 울릉고 방문 특강, 3차시.
- 활동 주소: `/activity/ulleung-high-session-3`.
- 기존 9월 19일 자료실의 표시 제목을 3차시로 수정했다. 이미 공유된 `/materials/ulleung-high-lesson-2` 주소와 PDF 원본은 유지했다.
- 사진 2장의 원본은 사용자의 Downloads에만 있다. 공개본은 얼굴·머리 영역을 5×5 픽셀로 축소 후 확대하여 모자이크하고 1600×1200 WebP로 저장했다. EXIF는 포함하지 않는다.
- 사용자가 원본에 모자이크만 적용하도록 명시적으로 승인했다. 이미지 생성은 사용하지 않았다. 처리 코드는 `scripts/prepare-september19-photos.mjs`에 있다.
- 수업 설명은 사용자 확인 내용과 사진의 발표 화면에 보이는 항목을 기준으로 작성했다. 참석자 이름, 인원, 학생 반응과 성과는 추가하지 않았다.
