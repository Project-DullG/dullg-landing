# 《유리 너머의 목소리》 웹사이트 통합

2026-09-13. 로컬 구현과 코드 검사 결과다. 사람의 플레이 평가나 Steam 심사 통과를 뜻하지 않는다.

## 실행과 수정 위치

- 소개: `/games/tide-room`
- 게임: `/play/tide-room`
- 홈과 `/mini-projects`에서 소개 페이지로 이동한다.
- 실행 코드: `components/tide-room/`
- 장면·인물 이미지와 음악: `public/assets/tide-room/`
- 사건 진행 조건: `engine.ts`, 대사: `dialogue.json`, 서술: `prose.json`, 단서 본문: `clues.json`.
- 화면 설명과 조사 기록: `game-guide.tsx`, `case-brief.tsx`.
- 읽던 위치 검증: `reader-state.ts`. 저장된 조사 행동이 현재 기록과 일치할 때만 위치를 복원한다.

이 사이트에서 실행할 게임은 위 파일을 수정한다. 기존 제작 시스템의 `truth-studio-ui`는 원본을 가져온 위치이며, 양쪽 파일이 자동으로 동기화되지는 않는다. 플레이에 쓰지 않는 전체 진실표와 제작자 문서는 사이트로 옮기지 않았다.

## 이번 변경

기존 게임을 별도 서버나 iframe 없이 Next.js 페이지에서 실행하도록 옮겼다. 팝업은 Base UI로 구성하고, 버튼과 음량 조절에는 기본 HTML 컨트롤을 사용했다. 종료는 확인 후 소개 페이지로 돌아간다.

조사 기록에 풀어야 할 질문을 표시한다. 문서의 내용, 인물의 주장, 직접 확인한 사실을 구분한다. 결말의 펼침 항목에는 플레이 중 얻은 기록만 나오며, 이미 끝난 조사를 계속하라고 지시하지 않는다.

읽던 대사, 도입 위치와 최근 300개 대화 기록을 같은 브라우저에서 복원한다. 음량·글자 크기·조사 지점 표시·화면 움직임 설정도 저장한다. 소리는 방문 때 자동으로 켜지지 않는다. 조사 진행 파일의 기존 v2 형식은 유지한다. 파일로 다른 기기에 옮기는 대상은 조사 진행이며, 대사 위치와 표시 설정은 해당 브라우저에 남는다.

이미지는 WebP로 제공하며 가까운 장면만 미리 읽는다. 인물은 배경을 제거한 이미지다. 공개 미디어 전체는 약 5.1 MB이며 음악을 포함한다. 이 크기는 실제 로딩 시간 측정값이 아니다.

소개 페이지는 한국어·영어 안내를 제공한다. 게임 본문은 한국어 전용이다.

Next.js와 eslint-config-next를 16.3.5로 갱신했다. 갱신 후 프로덕션 의존성 감사에서 critical/high 항목은 0개, moderate 항목은 7개였다. 남은 항목은 Firebase Admin과 그 의존성, baseline-browser-mapping 관련이다. 전체 개발 의존성까지 취약점이 없다는 뜻은 아니다.

## 검사

- `npm run test:tide`: 51개 진행·자료·SSR·이미지 처리·읽던 위치·사용자 유형별 동작 검사, 저장 오류 9개, 효과음 모의 검사 통과.
- `node --experimental-strip-types --test tests/*.test.mjs`: 기존 사이트 검사 112개 통과.
- Next.js 프로덕션 빌드와 게임 파일·middleware ESLint 검사 통과.
- `node scripts/check-tide-http.mjs http://localhost:3002`: 페이지 5개, 미디어 25개, 음악 부분 다운로드(206), 로그인 이동 2개 통과. 브라우저는 사용하지 않았다.
- Next.js가 영문 경로를 내부 경로로 다시 처리할 때 언어 헤더를 유지하도록 middleware를 수정했다.
- 사이트 전체 영문 검사에는 기존 홈 영상, 스피킹 메뉴, 개인정보 안내 등의 번역 누락이 남아 있다. 전체 사이트 검사가 통과했다고 보고하지 않는다.
- 사용자 요청에 따라 브라우저 조작, 실제 음향 재생, 모바일 화면 촬영은 하지 않았다.

## 판매판을 판단할 때 남은 확인

현재는 웹에서 실행하는 한국어 게임이다. Steam용 실행 파일, Steamworks 연결과 스토어 등록은 만들거나 제출하지 않았다.

초견 플레이어가 도움 없이 조사 목적을 설명할 수 있는지, 어느 단서에서 오래 멈추는지, 두 결말의 선택 이유가 납득되는지는 실제 플레이로 확인해야 한다. 화면에서 물건을 찾는 난도, 인물 그림과 대사창의 겹침, 음악과 효과음의 실제 음량도 아직 평가하지 않았다. 음악은 사용자가 제공한 `Ink in the Files.m4a`이며 유료 배포 권리의 증빙은 별도로 확인해야 한다.

따라서 현재 판정을 ‘판매 가능한 완성품’으로 쓰지 않는다. 코드로 확인한 진행 안정성과 사람이 판단할 이야기의 재미를 구분한다.

## 사용자 유형별 추가 수정

처음 하는 사람, 대사를 꼼꼼히 읽는 사람, 중단했다 돌아오는 사람을 기준으로 15개 불편을 검토하고 수정했다. 구체적인 변경과 검사 범위는 `tide-room-persona-review.md`에 기록했다. 이번 실행 환경에서 기본 Turbopack 빌드는 내부 포트 생성 제한으로 실패해 `npm run build -- --webpack`으로 빌드했다. 프로젝트의 기본 빌드 설정은 바꾸지 않았다.

도입·대사·단서·결말의 문장은 `tide-room-editorial-review.md` 기준으로 교정했다. 기존 조사 진행은 유지하며, 이전 문장으로 저장된 대사 위치는 교정판에서 다시 기록한다.

## 제목과 대사·조작 안내 화면

제목을 《유리 너머의 목소리》로 바꿨다. 기존 `/play/tide-room` 주소와 조사 저장 키는 유지한다. 대사에는 화자 초상·역할을 표시하고, 인용 대사를 서술과 구분한다. 도입의 조작 설명은 `investigation-tutorial.tsx`의 별도 안내 카드로 표시하고 지난 대화에는 넣지 않는다.
