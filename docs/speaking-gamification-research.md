# 반복 말하기와 낚시 수집의 통합 설계

이 설계는 토익스피킹 코스를 따르는 날과 짧게 반복 연습하는 날을 모두 지원한다. 영어 문항을 듣고 말하는 행동을 마치면 물고기와 낚시 경험치를 얻고, 쌓인 경험치로 새 어종·수조 배경·전시 자리를 연다. 물고기를 선택하면 다시 말하기 연습으로 들어갈 수 있게 하여 수조를 보는 행동도 학습의 시작점으로 쓴다.

현재 제품의 학습 자료는 64문항, 문장 아래 한글 발음 안내, Annie 제작 음성으로 구성되어 있다. 녹음·업로드·자동 발음 채점은 제공하지 않는다. 완료 기록은 학습자가 소리 내어 연습했다고 직접 확인한 기록이다. 낚시 레벨이나 희귀 물고기는 영어 실력·공식 점수·졸업요건 충족을 뜻하지 않는다.

아래 수치와 흐름을 사이트 통합본에 구현했다. 전체92개 자동 검사와 빌드를 통과했으며, 로컬 데이터베이스와 모바일 브라우저에서 저장·먹이주기·보상·이어하기를 확인했다. 운영 반영 상태와 검증 범위는 마지막 표를 따른다. 학술 근거, 서비스 사례, 제품 설계 판단을 구분한다.

## 1. 해결할 문제와 설계 선택

코스만 제공하면 정해진 하루 분량을 시작하기 어려운 날에는 무엇을 연습할지 다시 골라야 한다. 유형별 문항 목록만으로는 어디서 멈추고 언제 같은 문항을 다시 말할지도 분명하지 않다. 따라서 코스와 별개로 끝이 정해진 짧은 묶음을 제공한다. 학습자가 원하는 유형을 고르거나, 저장한 문항을 꺼내거나, 수조의 물고기에서 연습을 시작할 수 있게 한다.

수집품을 단순히 한 마리씩 더하는 방식은 같은 종이 반복될 때 달라지는 정보가 적다. 이를 해결하기 위해 종마다 크기와 무늬가 다른 개체를 남기고 최고 크기 기록을 표시한다. 누적 연습은 레벨로, 장기간 남는 변화는 새 어종과 수조로 보여 준다. 중복 물고기를 없애거나 다른 재료로 바꾸는 조작은 요구하지 않는다.

| 비교 후보 | 학습자가 해야 하는 일 | 기대하는 역할 | 선택 결과와 이유 |
|---|---|---|---|
| 코스 완료 후 같은 물고기만 누적 | 정해진 코스 진행 | 보상 규칙이 가장 단순함 | 기본 보상 경로로 유지. 같은 종의 개체 차이와 코스 밖 연습이 부족하여 단독안으로는 사용하지 않음. |

## 2. 학습과 수조를 오가는 흐름

### 코스 공부

7일·14일·30일 코스와 60·90·120분 계획을 유지한다. 코스의 하루는 복습, 첫 답변과 퀴즈, 소리 교정, 재시도와 적용, 정리의 다섯 묶음이다. 각 묶음을 마칠 때 물고기 한 마리와 20 XP를 얻는다. 마지막 물고기의 별 표시는 하루 정리 완료를 뜻하며 크기 등급이나 희귀 무늬와 구분한다.

기존 30개 학습일의 90개 분량 계획과 코스 보상 150마리·12종은 바꾸지 않는다. 다른 코스로 전환하거나 이전 학습일을 다시 보아도 완료 기록을 중복 지급하지 않는다. 레벨 도입 때문에 이미 수행한 공부를 다시 하도록 요구하지 않는다.

### 짧은 반복 연습

안내문 읽기, 질문에 바로 답하기, 시간·장소 말하기, 정보 바로잡기, 선택에 이유 붙이기, 사진 설명의 여섯 묶음을 둔다. 각 묶음은 서로 다른 문항 세 개로 구성한다. 첫 세 문항은 영어 음성과 한글 안내를 참고해 말하고, 다음 세 단계에서 같은 문항에 다시 답한다. 두 번째 차례에는 답변 예문과 한글을 기본적으로 가린다. 읽기 원문, 사진, 일정표는 시험에서 주어지는 자료이므로 유지한다.

막히면 예문을 다시 열 수 있고, 다음에 연습할 문항을 직접 담을 수 있다. 저장한 문항이 한두 개뿐이어도 연습은 허용한다. 다만 추가 물고기는 서로 다른 세 문항을 두 차례씩 마친 묶음에서만 지급한다. 한 문항을 연속해서 누르는 방식으로 보상을 대신 얻을 수는 없다.

인출 연습 메타분석은 예문을 다시 보는 것 외에 답을 떠올리는 활동을 넣을 근거가 된다. 그러나 완료 버튼을 누른 사실만으로 실제 인출이나 답변의 정확성을 확인할 수는 없다. 같은 날 두 차례 말하는 것과 날짜를 나눈 복습도 구분해야 한다.[7](https://pubmed.ncbi.nlm.nih.gov/33683913/)[8](https://onlinelibrary.wiley.com/doi/10.1111/lang.12479)

### 물고기 먹이주기

수조에서 보유한 물고기를 선택하면 해당 개체를 대상으로 한 짧은 말하기 연습을 시작한다. 기존 학습 자료 중 서로 다른 세 문항을 배정하고 같은 두 차례 연습 구조를 사용한다. 배정된 문항은 진행 중에는 고정한다. 다시 접속하거나 화면을 바꿨다는 이유로 새 문항을 계속 뽑지 않는다.

먹이주기에서 제공하는 것은 물고기 선택에 연결된 연습 경로와 완료 반응이다. 접속한 시간에 따라 먹이가 생기거나 클릭만으로 먹이를 주는 기능은 두지 않는다. 쉬었다고 물고기가 굶거나 사라지지 않으며, 포획할 때 정해진 크기도 먹이주기로 다시 계산하지 않는다. 개체를 선택한 결과가 연습 화면에서 보이도록 하되, 허기·건강·먹이 재고 같은 새 수치를 추가하지 않는다.

일반 반복 연습과 먹이주기는 한국 시각 날짜당 물고기 한 마리·20 XP라는 추가 보상을 공유한다. 한쪽에서 오늘 보상을 받았다면 다른 쪽에서도 연습과 완료 기록은 계속 제공하되 두 번째 추가 물고기는 지급하지 않는다. 시작 전에 이 조건을 보여 주어, 먹이주기 버튼마다 별도 보상이 생기는 것으로 오해하지 않게 한다.

## 3. 레벨·확률·확정 보상

| 항목 | 설계 기준 | 기준을 정한 이유 |
|---|---|---|
| 코스 보상 | 코스 묶음당 물고기 1마리·20 XP | 기존 다섯 묶음과 지급 수를 유지함. |
| 자유 연습 보상 | 서로 다른 3문항×2회 완주, 한국 시각 날짜당 1마리·20 XP | 짧게 공부한 날도 보상을 남기되 같은 날 회차를 무한 반복해 수집을 늘리지 않음. |
| 레벨 | Lv.1~10, 누적 XP 기준 | 다음 변화까지 남은 양을 한 숫자로 보여 줌. |
| 오로라 무늬 | 일반 포획에서 Lv.1 12%, 레벨당 2%p 증가, Lv.10 30% | 레벨 상승 후 새 포획의 분포가 바뀌도록 함. |
| 코스 확정 보상 | 7·14·21·28일차 마지막 물고기는 특대 오로라 | 무작위 결과가 좋지 않아도 정해진 코스 진행으로 희귀 개체를 얻도록 함. |
| 쉬는 날 | 경험치·개체·해금 내용 유지 | 복원권·출석 연장·회수 규칙을 추가하지 않음. |

여기서 코스의 ‘학습일’과 한국 시각의 ‘날짜’는 다르다. 코스의 보상은 정해진 학습일의 다섯 묶음에 연결되고, 반복 보상 상한만 달력 날짜로 계산한다. 같은 날짜에 코스 여러 학습일을 마치는 경우까지 막지 않는다면 전체 보상을 ‘하루 최대 6마리’라고 설명해서는 안 된다. 매일 코스 한 학습일과 반복 한 묶음을 마친 경우에 한해 하루 여섯 마리가 된다.

구현한 레벨 표는 다음과 같다. 요구 XP가 20의 배수가 아닌 레벨은 실제로 도달 가능한 다음 XP에서 열린다. 예를 들어 Lv.3의 기준은 250 이상이며, 20 XP 단위로만 얻으면 260 XP에서 도달한다.

레벨과 확률 값은 학술 연구에서 가져온 수치가 아니다. 초기 포획에서 결과를 비교할 수 있고, 코스 30학습일의 기존 150마리만으로도 3,000 XP에 도달하도록 정한 제품 설계값이다. 자유 연습만 하는 경우에도 XP는 쌓이지만, 코스에 배정된 12종의 해금 조건과 코스 7일 보상을 대신 충족하지는 않는다.

오로라 12~30%는 보장 개체를 제외한 일반 포획 비율이다. 확정 오로라가 포함된 전체 수집품에서는 오로라 비율이 이보다 높을 수 있다. 작은 표본의 한 계정에서 실제 비율이 기준과 다르게 나오는 것은 가능하다. 화면에는 ‘일반 포획의 오로라 확률’이라고 쓰고, 보장 조건을 별도로 설명한다. 포획 후 레벨이 올라도 과거 개체의 무늬는 바뀌지 않는다.

## 4. 새 어종과 중복 개체의 가치

기존 코스의 12종에 해마·가오리·개복치·아귀·상자복·톱상어 여섯 종을 추가했다. 새 여섯 종은 반복 연습과 먹이주기의 공유 일일 보상에서 얻는다. 기존 코스의 어종 배정이나 이미 받은 개체를 새 어종으로 바꾸지 않는다.

추가 어종은 레벨 2·3·4·6·8·10에서 차례로 열린다. 새로 열린 종은 다음 해당 반복 보상에서 확정적으로 한 마리 지급하고, 처음 받은 뒤에는 일반 후보군에 포함한다. 이를 통해 레벨이 올라 새 종이 열렸다는 안내를 보고도 오랫동안 그 종을 얻지 못하는 상황을 줄인다. 어종별 3마리·7마리 같은 별도 누적 조건은 두지 않는다.

이 확정 지급도 하루 추가 물고기 한 마리 안에 포함한다. 해마를 처음 받는 날이라고 별도의 무료 개체를 더 지급하는 방식이 아니다. 여러 추가종이 동시에 열리면 해금 레벨이 낮은 종부터 아직 받지 않은 종을 지급한다. 포획으로20 XP를 얻어 오른 레벨을 그 포획에 바로 적용한다. 우선순위가 바뀌더라도 이미 받은 개체를 다시 추첨해서는 안 된다.

모든 어종은 아담·보통·대형·특대의 네 크기 등급과 기본·반점·오로라의 세 무늬를 가진다. cm는 게임 안의 수집용 수치다. 실제 물고기의 몸길이나 생물학적 성장 모델로 설명하지 않는다. 어종마다 크기 범위를 다르게 두고, 등급은 그 어종 안의 크기로 판단한다. 작은 어종도 특대 개체를 얻을 수 있어야 한다.

도감은 어종 수, 어종별 보유 수, 최고 크기, 발견한 무늬를 보여 준다. 같은 어종이 다시 나와도 개체의 크기·무늬·획득 경로를 남기고 전시할 개체를 선택할 수 있게 한다. 최고 크기를 경신하지 못한 개체를 실패라고 표시하거나 자동 판매하지 않는다. 특정 개체를 대표로 바꾸는 행동에는 추가 XP나 재추첨을 주지 않는다.

수조 배경은 Lv.1·4·7에서 늘어나고 전시 자리는 3·5·7개로 확대한다. 전시 자리는 보관 상한이 아니다. 전시하지 않은 개체도 도감에 남는다. 높은 레벨에서 이전 배경을 선택하더라도 이미 늘어난 전시 자리가 줄지 않도록 한다. 배경3종과 어종18종의 세 무늬 이미지를 제작했다. 모바일 배치를 확인했으며, 그림의 차이가 학습 지속에 미치는 효과는 검증하지 않았다.

## 5. 연구가 지지하는 부분과 지지하지 않는 부분

| 근거 | 확인된 내용 | 이 설계에서의 해석 |
|---|---|---|
| 교육 게임화 메타분석 | 2024년 35개 개입·2,500명에서 내적 동기 효과는 `g=.257`로 작고 연구 간 차이가 컸다. 대부분 자기보고 측정이었다.[1](https://link.springer.com/article/10.1007/s11423-023-10337-7) | 수집이 모든 학습자에게 같은 동기를 줄 것이라고 가정하지 않는다. 선택형 진입과 규칙 설명을 제공한다. |
| 엄격한 설계의 하위분석 | 2020년 메타분석은 전체 평균에서 긍정적 결과를 보였지만 엄격한 연구만 남기면 동기와 행동 효과가 유의하지 않았다.[2](https://link.springer.com/article/10.1007/s10648-019-09498-w) | 레벨을 넣었다는 이유로 학습 지속 효과가 입증됐다고 말하지 않는다. |
| 개별 게임 요소 실험 | 창고 작업 시뮬레이션에서 요소 묶음에 따라 유능감·관계감 결과가 달랐다. 419명 완료 후 331명을 분석했고 장기 언어 학습은 검사하지 않았다.[3](https://d-nb.info/1309619042/34) | 물고기·배경·표시 숫자의 효과를 하나의 ‘게임 효과’로 묶어 단정하지 않는다. |
| 부정적 종단 결과 | 16주 대학 수업 비교에서 성적과 연결된 배지·순위표 집단의 동기·만족도가 낮아졌다. 무작위 배정은 아니었다.[4](https://doi.org/10.1016/j.compedu.2014.08.019) | 공개 경쟁과 의무 수집을 추가하지 않는다. 개인 수조와 선택형 반복을 사용한다. |
| 외적 보상의 조건 | 128개 실험 메타분석은 일부 예상된 조건부 보상에서 내적 동기 감소를 보고했다. 다른 재분석은 과제 흥미와 지급 조건에 따라 결과가 다르다고 결론지었다.[5](https://selfdeterminationtheory.org/wp-content/uploads/2014/04/1999_DeciKoestnerRyan_Meta.pdf)[6](https://pmc.ncbi.nlm.nih.gov/articles/PMC2731358/) | 보상을 모두 해롭거나 모두 유익하다고 판단하지 않는다. 성장 표시보다 실제로 수행한 학습 행동을 먼저 설명한다. |
| 인출과 간격 학습 | 교실 인출 연습 222개 연구·48,478명에서 평균 `g=.499`. 제2언어 간격 학습 48개 실험·3,411명에서도 긍정적 효과를 보고했다.[7](https://pubmed.ncbi.nlm.nih.gov/33683913/)[8](https://onlinelibrary.wiley.com/doi/10.1111/lang.12479) | 두 번째 말하기에서 예문을 가리고, 다른 날에 같은 문항을 다시 꺼낼 경로를 둔다. 발음·공식 점수 효과로 확대하지 않는다. |

`g`는 집단 간 차이를 표준편차 단위로 나타낸 값이다. `g=.499`를 점수 49.9% 상승이나 학습자 절반의 성공으로 해석할 수 없다. 위 연구들은 이 제품의 20 XP, 세 문항, 하루 한 번 추가 포획, 희귀 확률, 새 어종 해금 레벨을 검증하지 않았다. 물고기 그림을 추가한 효과와 인출 연습 자체의 효과도 구분해야 한다.

실제 서비스 사례에서도 행동과 보상의 관계를 참고할 수 있다. Finch는 선택한 목표를 정해진 횟수 완료하면 수집품을 제공한다. Duolingo는 작은 학습 단위와 하루 목표를 분리한 자체 실험에서 재방문 증가와 하루 목표 완료 감소를 함께 보고했다. 이는 짧은 연습의 접근성과 전체 분량 완료가 서로 다른 지표라는 점을 보여 주지만, 개발사 자체 보고를 토익스피킹 실력 향상으로 바꿔 해석할 수는 없다.[9](https://help.finchcare.com/hc/en-us/articles/37780505907469-Using-the-Micropet-Lab)[12](https://blog.duolingo.com/improving-the-streak/)

## 6. 모바일 화면과 보상 안내

반복 연습 화면의 중심은 영어 문장과 그 아래 한글 안내다. 본문에는 듣기·중지와 한글 보기·가리기를 유지한다. 배경·레벨·획득 애니메이션을 문장 사이에 넣지 않는다. 음성을 듣는 도중 수조 효과음이 겹치지 않게 하고, 움직임 줄이기 설정에서는 장식 애니메이션을 멈춘다.

다음 문항으로 넘어가면 새 문항 제목으로 포커스를 옮긴다. 특히 사진이나 긴 지문 아래에서 완료한 뒤 다음 문항의 하단 버튼만 보이는 상황을 막아야 한다. 완료 확인은 새 단계마다 해제하고, 저장 실패 시 완료한 것처럼 화면을 진행하지 않는다. 한글을 가려 다시 말하는 단계에서도 필요하면 예문을 잠깐 열어 확인할 수 있게 한다.

보상은 새로 지급했을 때만 한 번 안내한다. 다음 단계나 다른 묶음을 시작했는데 이전 물고기의 ‘+20 XP’가 그대로 남으면 추가 지급으로 오해할 수 있으므로 지운다. 보상을 받지 않은 완주도 ‘오늘 추가 보상은 이미 받았고, 연습 횟수는 기록했다’고 설명한다. 레벨 상승과 새 어종 해금이 함께 일어나면 현재 결과와 다음에 받을 결과를 구분해서 보여 준다.

수조에서는 어종뿐 아니라 선택한 개체의 크기와 무늬가 확인되어야 한다. 작은 화면에서 물고기가 장식과 겹치거나 비슷한 색 때문에 구분되지 않으면 이미지나 배경 배치를 수정한다. 수조를 더 꾸미기 위한 설정 메뉴보다 물고기 선택·전시·먹이주기·도감 확인을 우선한다.

## 7. 기록 보존과 중복 지급 방지

| 실패 조건 | 필요한 처리 |
|---|---|
| 저장 응답이 늦어 같은 완료 요청을 다시 보냄 | 같은 회차·단계는 한 번만 반영한다. 완료 횟수·XP·개체를 다시 추가하지 않는다. |
| 전날 완료 요청이 자정을 넘겨 다시 도착함 | 이미 끝난 회차임을 먼저 확인한다. 오늘 추가 보상으로 재해석하지 않는다. |
| 일반 반복과 먹이주기를 서로 다른 기기에서 동시에 완료함 | 계정의 같은 일일 보상 기록을 트랜잭션으로 검사한다. 둘 중 한 번만 지급한다. |
| 쉬운 문항 하나만 반복하거나 중간 단계를 건너뜀 | 보상은 서버가 배정한 서로 다른 세 문항의 두 차례 완료에만 연결한다. |
| 연습 중 저장 목록을 바꿈 | 이미 시작한 묶음의 문항은 그대로 둔다. 변경 사항은 다음 묶음부터 반영한다. |
| 레벨·배경·대표 개체가 바뀜 | 과거 개체의 크기·무늬·어종은 그대로 둔다. |
| 기존 계정에 새 필드가 없음 | 코스 기록을 유지한 채 필요한 기본값을 적용한다. 이전 150개 코스 지급 위치와 어종을 다시 배정하지 않는다. |
| 계정을 바꾸거나 클라이언트에서 UID·XP·확률을 보냄 | 검증된 서버 계정과 서버 규칙만 사용한다. 다른 계정의 기록을 합치지 않는다. |

포획의 크기·무늬는 계정과 획득 위치에 따른 고정 값으로 계산하거나, 결정한 결과를 저장한다. 어느 방식을 사용하든 규칙 버전과 포획 당시 레벨을 보존하여 새 규칙이 과거 개체에 소급 적용되지 않도록 해야 한다. 추가 어종 첫 지급 여부도 실제 보유 기록과 일일 지급 기록에 일관되게 반영한다.

여기서 서버가 검증하는 것은 회차·단계·문항·중복·날짜다. 소리 내어 말했는지와 발음이 맞았는지는 검증하지 않는다. 그 한계를 보상 화면이나 내부 지표에서 숨기지 않는다.

## 8. 수치 확인과 사용 후 측정 계획

배포 전에는 합성 계정을 이용해 각 레벨의 일반 포획 분포를 확인한다. 계정별 표본과 전체 표본을 나누고, 보장 물고기를 일반 확률 계산에서 제외한다. 크기 네 등급과 무늬 세 종류가 모두 나오는지, 해금 전 어종이 나오지 않는지, 새 어종 첫 보상이 정해진 우선순위를 따르는지도 검사한다. 같은 입력을 다시 계산했을 때 결과가 같은지 확인한다. 이 검사는 보상 분포와 구현을 검사하는 것이며 재미나 학습 효과를 검증하는 실험은 아니다.

사용 후에는 다음 지표를 서로 구분한다. 별도 녹음이나 외부 분석 서비스를 추가하지 않고, 이미 남기는 완료 기록과 학습자의 직접 보고로 시작한다. 아직 기록하지 않는 항목은 추가 기록 여부를 결정한 뒤 수집하며, 과거 행동을 추정해 채우지 않는다.

| 확인할 질문 | 확인할 자료 | 해석할 때 주의할 점 |
|---|---|---|
| 짧은 연습이 새 공부 시작에 도움이 되는가 | 반복 시작·완주 회차와 중단 위치, 시작 경로 | 페이지 조회나 수조 클릭만으로 공부했다고 집계하지 않는다. |
| 다음 날 다시 연습하는가 | 한국 시각 날짜별 실제 완료 기록 | 날짜별 재방문과 연속 출석을 구분한다. 쉬는 날을 실패 점수로 만들지 않는다. |
| 보상 때문에 한 유형만 반복하는가 | 완료한 고유 문항 수와 유형 분포 | 어려운 유형을 피하는지 직접 확인하고, 전체 완료 횟수만 보고 개선이라고 판단하지 않는다. |
| 정규 코스를 덜 하게 되는가 | 코스 묶음 완료와 자유 연습 완료를 분리한 추이 | 짧은 연습이 늘어도 코스 진행이 줄 수 있다. 두 지표를 함께 본다. |
| 같은 답을 가리고 다시 말할 수 있는가 | 다음 학습일의 자기보고와 실제 텍스트 답변이 있는 경우 그 내용 | 텍스트로 발음·강세를 평가하지 않는다. 관찰하지 않은 성공을 기록하지 않는다. |
| 수집 규칙을 이해하는가 | 보상 미지급·해금·확률 관련 질문과 사용 중 막힌 위치 | 질문이 없다는 사실만으로 규칙을 이해했다고 단정하지 않는다. |
| 수조가 공부를 방해하는가 | 학습자가 보고한 조작 부담, 모바일 화면에서 가려진 내용 | 화면에 머문 시간과 집중·학습 성과를 같은 것으로 취급하지 않는다. |

첫 사용에서는 두 학습자가 3문항 연습을 시작하고 끝내는 과정, 한글 없이 다시 말하는 과정, 오늘 보상 여부를 이해하는 과정을 확인한다. 이후 충분한 사용 기록이 쌓이면 같은 문항만 반복하는지와 다른 날에 돌아오는지를 살핀다. 작은 인원의 관찰은 문구·단계·보상 배분을 수정하는 자료로 사용한다. 대조 조건과 충분한 표본을 갖춘 연구를 하기 전에는 낚시 기능이 학습 지속이나 점수를 높였다는 인과 결론을 내리지 않는다.

보상 상한이나 확률을 조정할 때는 어느 행동이 왜 달라지기를 기대하는지 먼저 기록한다. 한 번에 여러 규칙을 함께 바꾸면 원인을 해석하기 어려우므로 하나씩 바꾸는 편이 낫다. 새 규칙을 적용하더라도 이전에 받은 물고기와 완료 기록은 유지한다.
