# 퇴원일 사이트 적용

사용자가 제공한 `퇴원일_그래픽게임_v2`를 바탕으로 적용했다. 원본 이야기, 분기, 퍼즐, 그림은 유지했다.

## 배치

- 미니 프로젝트 목록에서 소개 페이지 `/games/discharge-day`로 이동한다.
- 게임은 `/assets/discharge-day/index.html`에서 실행한다. 중첩 iframe은 사용하지 않는다.
- 소개 페이지는 한국어와 영어를 제공한다. 게임 본문은 한국어다.
- 실행에 필요한 그림과 스크립트만 공개 폴더에 둔다. 원본 기획서와 테스트 자료는 공개 자산에 포함하지 않는다.

## 화면 수정

- 장면, 본문, 선택지, 소지품을 문서 순서대로 배치해 서로 겹치지 않도록 했다.
- 장면의 원본 비율을 유지한다. 900px 이하에서는 조사 대상을 장면 아래 버튼으로 선택한다.
- 선택지 터치 영역은 최소 44px이다. 설정 창은 높이가 짧은 화면에서 스크롤된다.
- 그림을 HTML 내 Base64에서 개별 WebP 파일로 분리했다.
- 자동 저장과 저장 파일 내보내기는 원본 기능을 유지한다.

## 수정 및 검증 명령

`games/discharge-day/src`를 수정한 뒤 `node scripts/build-discharge.mjs`로 공개 파일을 생성한다.

- `node games/discharge-day/tests/test_logic.js`: 분기와 퍼즐 검증
- `node scripts/test-discharge.mjs <origin>`: 실제 브라우저에서 분기와 배치 검증
- `npm run build -- --webpack` 및 `node scripts/test-site.mjs`: 사이트 통합 검증

Chromium에서 360×780, 390×844, 768×1024, 1440×900, 812×375 화면을 검사했다. 12개 경로, 61개 장면, 다섯 결말을 확인했다. 저장 후 이어하기와 설정 창 조작도 검사했다. 실제 iOS 기기에서의 검증은 별도로 필요하다.
