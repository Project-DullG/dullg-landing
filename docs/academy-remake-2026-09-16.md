# 「집에가고 싶어!」 리메이크 소개 반영

- 운영 main을 기준으로 홈, 수업팩, 에피소드, 샘플 페이지를 수정했다.
- v3.1 인쇄 패키지에서 표지·영어 단서·공개 인물 표지·룰북 페이지를 추출했다.
- 작품 제목, 사건 시각, 열쇠 위치를 최신 내용으로 맞추고 기존 임의 목격담을 삭제했다.
- 인물의 비밀이 포함된 타임라인 미리보기를 인물 표지로 교체했다.
- 게임 자체의 4인·40~50분 이상 구성과 파일럿 예정인 4차시 영어 수업 운영안을 구분했다.
- 시놉시스와 룰 설명 MP4를 추가했다. 자동 재생하지 않으며 preload는 none이다. 전체 대본과 슬라이드 링크를 함께 제공한다.
- 한·영 페이지 4개를 390px와 1440px에서 검사했다. 가로 넘침, 이미지 로딩과 두 영상의 메타데이터 로딩을 확인했다.
- Next.js 빌드, 변경 파일 ESLint, 라이브러리 테스트 6개, 렌더링 테스트 6개를 통과했다.
- 다른 작업의 미커밋 파일은 포함하지 않았다.
