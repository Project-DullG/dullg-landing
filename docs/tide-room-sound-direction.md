# 시작 소리와 장치 연출

2026-09-13

- 시작 화면에서는 음악을 재생하지 않는다. 소리 설정의 기본값은 켜짐이며, 시작·이어 하기·처음부터 시작을 누르는 순간 재생을 요청한다.
- 시작 전에 소리를 끄면 무음으로 진행한다. 저장한 음량은 유지한다.
- 시작 화면에 소리 재생 여부를 표시한다. 재생을 브라우저가 거부하면 기존 오류 안내와 소리 버튼으로 다시 시도할 수 있다.
- 장치 덮개를 열고 닫는 조작이 받아들여졌을 때만 짧은 금속 마찰음과 낮은 타격음을 합성한다. 실패한 조작이나 저장 기록 복원에서는 이 효과음을 재생하지 않는다.
- 덮개 조작 뒤 화면 가장자리를 700ms 동안 어둡게 했다가 되돌린다. 화면을 흔들거나 밝게 번쩍이지 않으며 클릭을 막지 않는다.
- 새 대사 페이지는 180ms 동안 나타난다. 문장을 한 글자씩 기다리게 하지 않는다.
- 게임의 화면 효과 설정과 운영체제의 동작 줄이기 설정에 따라 새 연출을 끈다.

## 확인

진행·서버 렌더링 검사 51개, 저장 검사 9개, 효과음의 조작 매핑·중복 재생 제한·음소거·정리 모의 검사를 통과했다. 초기 화면의 소리 상태와 재생 안내를 검사에 추가했다. 실제 브라우저 클릭과 스피커 청취는 사용자가 정한 검증 범위에 따라 하지 않았다.
