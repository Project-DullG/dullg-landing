# 홈 구성과 추가 자료

## 2026-09-08 반영

- 홈 순서: 팀 소개 → 대표 작품 → 미니 프로젝트 → 교육 현장 → 영어 미스터리 수업팩 → 문의.
- 작품은 `HomeWorks`에서 대표작 한 편의 표지·줄거리·인원·시간을 보여주고, 나머지 두 편은 작은 이미지 목록으로 표시한다. `lib/works.ts`의 기존 공개 자료를 사용한다.
- 교육 사진에는 `lib/activities.ts`의 수업 내용을 함께 표시한다. 7월 생태관광 교육과 9월 울릉고 특강은 별개로 유지한다.
- 제작 과정은 `/about#process`로 옮긴다. 학원 관리의 자세한 기능·화면은 `/academy#tools`에 유지하며 홈에서는 `/demo`로 연결한다.
- 미니 프로젝트 목록은 퍼즐·카드 게임 6종과 아케이드 게임 3종으로 나눈다. 게임별 주소와 기능은 바꾸지 않는다.
- 사용하지 않는 이전 홈 대시보드 전용 스타일을 제거한다. 삭제한 소스는 Git 이력에서 복구할 수 있다.

## 추가로 받으면 좋은 자료

1. 대표작 구성품 전체 사진 한 장과 스포일러 없는 진행 예시 한 개. 기존 작품 상세의 소개 다음에 배치한다. 카드에 공개되지 않은 답이나 인물 비밀이 보이지 않는지 확인한다.
2. 7월·9월 수업의 공개 동의를 받은 결과물 한두 개. 이름·연락처·계정 정보는 제외하고 각 수업 활동 상세에 배치한다. 아직 준비 중인 영어 수업팩의 성과로 사용하지 않는다.
3. 제작자의 공개 이름 또는 활동명과 담당 업무. 소개 페이지에 원고·게임 구성·교육·개발 중 실제로 맡은 작업을 적는다. 사진은 선택 사항이다.

자료가 없을 때 가상 후기, 임의의 팀원, 성과 수치나 생성한 현장 사진으로 대신하지 않는다. 공개 가능 여부가 확인된 뒤 기존 상세 페이지에 추가하며 빈 섹션은 공개하지 않는다.
