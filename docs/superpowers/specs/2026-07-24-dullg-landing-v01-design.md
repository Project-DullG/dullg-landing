**날짜:** 2026-07-24
**상태:** 승인됨
**범위:** `app/page.tsx` 구조 정리 + 카피 수정 (B 방향)

---

## 1. 목적

학원 원장이 사이트에 들어왔을 때:
1. 제품이 무엇인지 바로 이해한다
2. 구성품과 수업 방식을 확인한다
3. 문의 또는 샘플 요청을 한다

## 3. 섹션별 상세 변경 사항

### 3-1. 히어로 (`landing-hero`)

**h1 (수정)**
- 현재: "내신이 끝난 뒤, 학생들이 영어로 사건을 해결합니다."
- 변경: "추리 게임으로 영어 읽기와 근거 말하기를 연습하는 4차시 수업 키트"
- `<em>` 강조는 "근거 말하기를 연습하는"에 적용

**부제 (수정)**
- 현재 `<p>`: "영어 단서를 읽고 질문하고, 추측하고, 반박하며 팀별 사건보고서를 완성하는 초6~중1 대상 영어 프로젝트 수업입니다."
- 변경: "초등 6학년~중학교 1학년 대상. 영어 단서를 읽고, 팀원과 의견을 비교하며, 사건 보고서를 완성합니다."

**CTA (수정)**
- 현재: 버튼 2개 (`<a>` + `<a>`) + landing-hero-sub 보조 p
- 변경: 버튼 1개만 남김 → `<a className="button button-dark" href="#apply">샘플 자료 요청 <span>↗</span></a>`
- text-link (`파일럿 운영 상담하기`) 제거
- `landing-hero-sub` p 태그 제거 (CSS에서도 해당 클래스 삭제)
- `landing-assurance` p 태그 제거

### 3-2. 문제 설명 (`landing-problem`)

현재 3개 문제 유지. 카피 일부 수정:

| 번호 | 현재 strong | 변경 |
|------|------------|------|
| 01 | "시험 이후 집중력이 떨어지는 학생" | 유지 |
| 02 | "활동형 수업을 준비해야 하는 교사" | 유지 |
| 03 | "수업 결과를 설명해야 하는 원장" | 유지 |

현재 span 설명 텍스트 유지. landing-value 블록("하나의 수업팩으로") 유지.

### 3-3. 수업 흐름 (`landing-flow`)

섹션 헤드 h2 아래 `<p className="landing-flow-note">`로 "(예시 구성 · 변경될 수 있습니다)" 추가.

기존 `lessonFlow` 4단계 유지:
- 01 READ THE CLUES
- 02 SHARE THE FACTS
- 03 TEST THE THEORY
- 04 WRITE THE REPORT

### 3-4. 제품 구성품 (`landing-materials`)

**현재 4종 → 6종으로 교체:**

| 번호 | 이름 | 설명 |
|------|------|------|
| 01 | 게임 카드 | 학생마다 다른 영어 단서가 담긴 역할별 카드입니다. |
| 02 | 스토리 책자 | 사건 배경과 인물 관계를 담은 이야기 자료입니다. |
| 03 | 워크북 | 단서 기록, 추론 과정, 최종 근거를 차시별로 씁니다. |
| 04 | 규칙서 | 수업 진행 순서와 역할 규칙을 담은 안내 자료입니다. |
| 05 | 교사용 진행안 | 차시별 진행 순서, 대본, 힌트와 정답을 포함합니다. |
| 06 | 수업 결과 리포트 샘플 | 학생 활동 기록을 정리한 학부모 전달용 예시 자료입니다. |

이미지는 기존 에셋 재사용 (01·03·05·06은 기존 이미지 유지, 02·04는 placeholder).
그리드: `materials-grid`를 `grid-template-columns: repeat(3, 1fr)` 3열 2행으로 변경.
`material-large`, `material-wide` 클래스 제거 (6개 균등 배치).

### 3-6. 문의 폼 (`landing-apply`)

**폼 필드 (현재 → 변경):**

| 현재 필드 | 처리 |
|----------|------|
| 학원명 (required) | → "기관명"으로 레이블 변경 |
| 담당자명 (required) | → "담당자 이름"으로 레이블 변경 |
| 연락 가능한 연락처 (required) | → "연락처 또는 이메일"로 변경 |
| 담당 학년 (select, required) | **제거** |
| 예상 학생 수 (optional) | **제거** |
| 요청 유형 (select) | → name="interest", 레이블 "관심 유형", options: 제품 자료 요청 / 데모 신청 / 파일럿 수업 문의 / 구매 문의 |
| 개인정보 동의 checkbox | 유지 |

`form-split` div 제거 (담당 학년·학생 수 필드 삭제로 불필요).

**제목 (수정):**
- 현재: "무료 검토자료 요청하기"
- 변경: "문의하기"

**버튼 (수정):**
- 현재: "무료 검토자료 요청하기"
- 변경: "문의 보내기"

**소개 copy (수정):**
- 현재: "4차시 커리큘럼과 1회차 학생용 단서 카드, 교사용 진행안 샘플을 보내드립니다."
- 변경: 관심 유형에 따라 적합한 자료나 일정을 안내드립니다.

## 4. CSS 변경 사항

- `.landing-hero-sub` 클래스 규칙 삭제 (요소 제거로 불필요)
- `.landing-assurance` 클래스 규칙 삭제 (요소 제거로 불필요)
- `.landing-benefits`, `.benefit-image`, `.benefit-copy`, `.benefit-list` 규칙 삭제
- `.landing-faq`, `.faq-list` 규칙 삭제
- `.landing-fit`, `.fit-grid`, `.fit-facts`, `.pilot-callout` 규칙 삭제
- `.materials-grid` 기본 `grid-template-columns` → `repeat(3, 1fr)`
- `material-large`, `material-wide` 클래스 규칙 삭제
- `.landing-flow-note` 신규 클래스 추가: `font-size: 12px; color: rgba(21,37,30,.5); margin-top: 12px;`

## 6. 성공 기준

- 첫 화면에서 제품이 무엇인지 1문장으로 이해 가능
- CTA 버튼이 1개 (샘플 자료 요청)
- 제품 구성품 6종 표시
- 수업 흐름 섹션에 "(예시 구성)" 표기
- 폼 필드가 기관명·담당자 이름·연락처/이메일·관심유형·동의 5개로 축소
- 제거된 3개 섹션이 DOM에서 완전히 사라짐
- 모바일(360px)·데스크톱(1280px)에서 레이아웃 깨짐 없음
