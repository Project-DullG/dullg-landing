## 서버와 저장

`lib/speaking/catalog`는 서버에서만 값으로 가져온다. 클라이언트는 타입과 인증 후 받은 화면 자료만 사용한다. 학습 문항·답변·퀴즈 정답을 public 파일이나 공통 JavaScript 번들로 내보내지 않는다. 이미지와 음성은 `private-assets/speaking`에 두고 모든 요청에서 인증한다. 모바일 음성의 바이트 범위 요청도 지원한다.

서버 전용 설정은 `SPEAKING_ACCESS_CODE`, `SPEAKING_SESSION_SECRET`이다. 비밀키는 최소 32자이며 코드와 함께 공개 환경변수에 넣지 않는다. 코드·비밀키를 변경하면 이전 접근 쿠키가 거부된다. 접근 쿠키는 HttpOnly/SameSite=Lax/운영 Secure, 12시간이며 Google UID와 현재 로그인 쿠키에 결합된다.

학습 GET·POST는 화면을 발급한 세션 식별자도 확인한다. 다른 창에서 계정을 바꾼 후 이전 화면으로 새 계정의 기록을 저장할 수 없다. 계정 변경·로그아웃은 다른 학습 창에 갱신 신호를 전달한다. 모든 학습 응답은 개인용 저장 금지이며 로그인되지 않은 요청에는 자료를 전달하지 않는다.

Firestore의 `speakingProgress/{uid}`에 version=1과 상태를 저장한다. 완료 순서와 중복을 같은 트랜잭션 안에서 검사한다. `speakingAccessAttempts/{sha256(uid)}`에는 입력 시각을 저장하고 최근 한 시간 다섯 번으로 제한한다. 브라우저에서 UID·보상 수·정답 여부를 결정하지 않는다. 현 Firestore rules는 이 두 컬렉션의 클라이언트 읽기·쓰기를 허용하지 않는다. Admin SDK만 사용한다.

사용자 기록 삭제 요청은 계정 소유자를 확인한 뒤 해당 UID의 speakingProgress 문서와 해시 UID의 speakingAccessAttempts 문서만 처리한다. 이 작업에서 실제 사용자의 학습 기록을 만들거나 삭제하지 않았다. Google 계정과 기존 학원 기록은 별도다.

## 음성 제작 상태

사용자가 승인한 R01의 Annie - Lifelike 목소리를 전체 문항에 적용했다. HeyGen 웹에서 같은 목소리·속도 1로 생성한 영상의 음성 트랙을 MP3로 저장했다. 본문·질문·답변 예문·발음 카드의 124개 듣기 위치가 121개 파일에 연결된다. 같은 사진 묘사 질문은 하나의 파일을 공유한다. 총 길이는 약 16분 17초다. 한글 표기는 음성 원고에 보내지 않는다.

화면에는 AI 제작 음성임을 표시한다. 기본 속도는 1.0배이며 0.85배 재생을 선택할 수 있다. 정보 제시형 10번 질문은 하나의 음성을 두 차례 재생한다. 모든 현재 문항에 제작 음성이 있어 기기 목소리 선택은 표시하지 않는다. 파일 오류가 나면 알리고 재시도하게 하며 다른 음색으로 자동 전환하지 않는다.

검사는 원고 전체 대응·분리 경계·파일 길이·SHA-256·무힌트 ASR 전사를 확인하는 기술적 내용 검사다. ASR 불일치는 두 번째 전사와 시각·구간 근거로 검토하고 별도 판단 기록을 남겼다. 시장 사진 예문의 의미가 바뀐 후보는 교체 제작했다. 모든 음성의 사람 청음·발음 감수를 완료했다는 뜻은 아니다. R01만 사용자가 전체 재생과 음색을 승인했다.

`lesson-audio.json`의 ready/contentChecked는 기술 확인을 뜻하고 reviewed는 실제 청취 승인과 구별한다. 나머지 파일의 reviewed는 false다. 실제 파일은 비공개 audio 폴더에 두며 정확한 영어 문자열과 파일 해시를 대조한다. 제작 근거와 설치 목록은 영어 공부 프로젝트의 `research/content-expansion-2026-09-09/audio/release-audio-verification.json`에 있다. 영상 원본·ASR 모델·사용자 기록·비밀키는 배포 패키지에 넣지 않는다.

## 배포 상태

기존 앱은 Vercel의 Next.js 서버다. 과거 Sites·Vinext 설정 파일만 보고 정적 사이트나 Worker로 바꾸지 않는다. 기존 Firebase 운영 설정을 재사용하며, 배포 시 서버 전용 스피킹 설정 두 개를 등록한다. 최종 게시 결과는 아래에 추가한다.

### 운영 환경에서 확인한 모듈 오류

첫 미승격 배포에서 Firebase Admin 14.3 → jwks-rsa 4.1 → jose 6.2의 CommonJS/ES Module 가져오기 오류가 발생했다. 로컬 Node 24에서 `--no-experimental-require-module`로 재현했다. Vercel은 해당 기능을 기본 비활성화하므로 운영 `NODE_OPTIONS=--experimental-require-module`을 설정했다. 의존성 버전이나 인증 검증을 낮추지 않았다. [Vercel 공식 Node 설정](https://vercel.com/docs/functions/runtimes/node-js/advanced-node-configuration)을 근거로 수정했으며 후속 미승격 배포에서 입장 페이지 200, 학습 페이지 307, 비로그인 API·음성 401을 확인했다.
