# 학생관리 화면

- `StudentWorkspace`: 실제 계정과 체험에서 공유하는 목록·검색·반 필터·등록·수정·삭제 확인 UI.
- `LiveStudents`: 기존 서버 액션으로 저장하며 계정별 인증과 학원 범위는 서버에서 유지.
- `AcademyDemo`: 가상 데이터만 React 상태에서 변경. Firebase, 서버 액션, 브라우저 저장소 사용 없음.
- `ScoreChart`: 실제 학생 상세와 체험에서 공유. 점수와 차시를 텍스트로 표시하고 시각 막대는 보조 표현.
- `scoreSummary`: 미입력은 평균에서 제외하고 0점은 포함. 비정상 숫자는 제외.

## 범위 및 검증 한계

- 실제 목록은 기존 조회 한도 100명을 유지하고 화면에 범위를 안내한다.
- 실제 차시 그래프는 최근 성적 50건 중 각 차시의 최신 기록을 사용한다.
- 체험에서는 학생 등록·수정·반 배정·삭제 및 차시 점수 변경을 제공한다. 반 생성, 출결, 결제는 포함하지 않는다.
- 실제 고객 데이터 생성·삭제는 검증 목적으로 실행하지 않는다. 로그인 계정에서의 저장·권한 회귀는 별도 테스트 계정 검증이 필요하다.
