# 사이트 구조 감사

## 감사 흐름

1. 홈: 브랜드 정체성에서 작품, 제작 방식, 교육, 문의로 이동
2. 작품: 현재 펀딩, 전체 작품, 지난 펀딩 기록 확인
3. 교육: 수업팩 개요에서 상세 자료로 이동
4. 자료실: 날짜별 교육 과정 선택 후 자료 열기
5. 소개: 팀 정체성, 업무 범위, 제작 원칙, 현재 상태 확인

## 주요 발견과 반영

- 홈이 브랜드 소개와 수업팩 신청 페이지 역할을 동시에 맡아 끝부분이 반복됐습니다. 활동 소개와 긴 신청 폼을 제거하고 공통 문의로 합쳤습니다.
- 소개 페이지가 영어 수업의 문제를 다시 길게 설명해 교육 페이지와 겹쳤습니다. 해당 구간을 제거하고 팀의 업무와 제작 원칙으로 바꿨습니다.
- 울릉고 9월 5일 자료가 울릉군 4월 18일 과정 안에 포함돼 있었습니다. 두 과정을 독립 게시글로 분리했습니다.
- 하위 교육 페이지에서 상단 메뉴의 활성 상태가 사라졌습니다. `/academy/*`에서도 교육 메뉴가 유지되도록 수정했습니다.
