# 지도·여행자 코스 보완 · 2026-09-23

## 지도

공식 울릉군 관광지도에서 빠져 있던 명소를 34개 작은 선 아이콘과 이름으로 추가했습니다. 케이블카, 모노레일 2곳, 군락지 2곳, 전통가옥, 박물관·기념관, 봉우리, 바위, 독도 명소 등이 포함됩니다. 기존 관광지 칸과 삽화에 이미 표시된 장소는 중복 추가하지 않았습니다.

- 아이콘은 약 8.8mm 안에 들어갑니다. 이동 칸은 20mm 정사각형·24mm 원형입니다.
- 지도판은 720×420mm, 이동 칸 30개를 유지합니다. 이동 규칙과 연결선은 변경하지 않았습니다.
- 관광지 아이콘은 공식 지도상의 상대 위치를 반영한 안내입니다. 측량 좌표나 별도 이동 칸이 아닙니다.
- 각 관광지에는 인근 기존 이동 칸을 메타데이터로 연결했습니다. 가는 안내선은 관광지 위치만 가리킵니다.
- 1차 검수: 큰 삽화를 작은 선 아이콘으로 교체했습니다.
- 2차 검수: 지도 전체를 다시 배치하고 기존 이동 칸·지명·경로와 새 아이콘·이름의 충돌을 검사했습니다. 경로는 선분 전체를 검사합니다. 독도 우측 이름표는 좁은 공간에 맞춰 줄이고 배치했습니다.
- 기본 지도와 예산 관리 포함 지도에 같은 34개 표시가 들어갑니다. 기존 30개 게임 지명의 배치 좌표는 유지했습니다.

## 여행자별 코스

8명의 기존 서사에 맞춰 서로 다른 기존 코스 카드 1장씩을 지정했습니다. 장소별로 방문하려는 이유를 1인칭으로 적었습니다. 여행자북 6쪽, 준비 화면, 새 게임 기본 배정, 규칙서 준비 문구가 같은 배정표를 사용합니다.

- 정하린 C09: 도동항·나리분지·태하
- 이도윤 C10: 통구미·대풍감·등대·관음도 (대풍감·등대는 하나의 칸)
- 김수진 C18: 성인봉·나리분지·저동항
- 박영호 C20: 사동항·저동항·나리분지
- 최미경 C07: 관음도·나리분지·태하
- 윤태성 C03: 봉래폭포·성인봉·나리분지
- 한정애 C13: 현포·천부해중전망대·삼선암
- 서재문 C16: 남양·통구미·태하

B6 128×182mm, 8쪽을 유지합니다. 저장된 게임의 이전 코스는 유지하며, 게임 안에서 책자를 열 때도 그 게임에서 받은 코스의 장소를 표시합니다. 업데이트 후 이전 코드가 남지 않도록 변경 모듈의 URL 버전을 올렸습니다.
