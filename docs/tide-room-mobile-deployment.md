2026-09-13

## 화면 수정

- 720px 이하에서 제목과 메뉴를 두 줄로 배치한다. 버튼 높이는 최소 44px다.
- 단서 목록과 검색창을 두 열로 배치하고 긴 목록은 안에서 스크롤한다.
- 대사 화면의 여백과 인물 그림 크기를 작은 화면에 맞춰 줄인다. 높이가 500px 이하인 가로 화면에는 별도 규칙을 적용한다.
- 팝업 높이를 현재 화면 높이에 맞추고 휴대전화 화면 가장자리의 여백을 반영한다.
- 검색창과 숫자 입력란의 글자는 16px 이상으로 표시한다. 브라우저 확대를 막지 않는다.

## 배포 기준

현재 운영 배포 `dpl_9o8YTYEcGLcBfiCKjJ8FLL2zYeKE`의 Git 소스 `c24d1d4fc9b66074fbb5248332537fabcc169d23`를 별도 폴더에 복원했다. 여기에 게임 파일, 홈과 게임 목록의 소개 카드, 소개·플레이 경로, 번역, 필요한 의존성과 언어 처리 수정을 추가했다. 작업 폴더 전체를 업로드하지 않았다. 환경변수 파일과 작업 중인 다른 기능은 포함하지 않았다.

파일별 해시와 배포 폴더는 `tide-mobile-release-files.json`에 기록했다. 이후 배포에서도 이 게임의 파일과 연결 코드를 포함해야 한다. 기존 Git 버전만 다시 배포하면 게임이 빠진다.

## 검사

- 진행 조건·서버 렌더링·컴포넌트 동작 검사 51개 통과.
- 저장 기록 검사 9개와 효과음 수명주기 모의 검사 통과.
- 배포용 소스와 작업 폴더의 Next.js 빌드 통과.
- 로컬 HTTP 검사: 페이지 5개, 미디어 25개, 음악 부분 요청 206, 비로그인 보호 경로의 이동 2개 통과.
- viewport-fit=cover를 확인했고 확대 제한은 넣지 않았다.

사용자의 요청에 따라 브라우저 조작과 실제 휴대전화 검사는 하지 않았다. 따라서 기기별 글줄 배치와 터치 조작의 최종 확인은 남아 있다.
