# 한국어·영어 사이트와 미니 게임

## 언어별 주소

- 한국어는 기존 주소를 사용합니다. 영어는 같은 주소 앞에 `/en`을 붙입니다.
- `EN`과 `한국어` 링크는 현재 페이지의 경로, 검색 조건, 앵커를 유지합니다.
- 작품 소개, 자료실 안내, 교육 안내, 문의, 로그인, 학원 관리 체험, 게임 UI를 번역합니다.
- 작품 표지, 예고편, 기존 발표자료와 PDF 원본은 번역하지 않았습니다. 해당 상세 페이지에서 원본 언어를 안내합니다.
- 작품의 영어 제목은 사이트 소개용 번역이며, 영문판 게임의 출시를 뜻하지 않습니다.

## 코드 구성

- `middleware.ts`: 주소에 따라 요청 언어를 지정하고, 기존 학원 관리 접근 제한을 적용합니다.
- `i18n/request.ts`: next-intl의 요청별 언어 설정입니다.
- `lib/i18n/translate.ts`: 문구, 숫자가 들어가는 게임 안내, 내부 링크 주소를 변환합니다.
- `lib/i18n/en.json`, `en-interface.json`: 영어 문구를 관리합니다.
- `components/i18n/link.tsx`: 내부 링크에 현재 언어를 적용합니다. 외부 주소와 파일 주소는 변경하지 않습니다.
- `lib/i18n/server.ts`, `sitemap.ts`: 언어별 메타데이터와 검색엔진용 주소를 만듭니다.

서버 컴포넌트와 클라이언트 컴포넌트가 같은 번역 함수를 사용합니다. 입력값, 저장된 기록, 게임 상태와 인증 정보는 번역하지 않습니다. 새 문구는 문장 전체로 등록하고, 숫자가 바뀌는 문장은 변환 규칙과 테스트를 함께 추가합니다.

## 추가 게임

| 게임 | 규칙 | 검증 내용 |
| --- | --- | --- |
| 세 개 한 줄 | 이웃한 두 칸을 바꿔 같은 모양을 세 개 이상 맞춥니다. 성공한 이동 30번 동안 점수를 모읍니다. | 첫 배치에 완성된 줄이 없는지, 연쇄 점수, 실패한 교환의 횟수 보존, 막힌 판 재배치 |
| 스네이크 | 먹이를 먹으며 벽과 몸을 피합니다. | 반대 방향 입력 차단, 입력 대기열, 충돌, 빈칸 먹이 생성 |
| 불 끄기 | 한 칸과 상하좌우의 불을 바꿔 모두 끕니다. | 풀 수 있는 문제 생성, 현재 배치의 해답, 가장자리 전환 |

기존 2048을 포함해 퍼즐·카드 8종, 아케이드 4종입니다. 새 게임은 추가 이미지 파일이나 외부 서비스 없이 React와 TypeScript로 구현했습니다.

## 검증

`npm test`는 빌드한 서버를 임시 포트에서 실행합니다. 공개 경로를 두 언어로 요청하고, 문구와 접근성 이름의 번역 누락을 검사한 뒤 기존 테스트와 게임 규칙 테스트를 실행합니다. 검사가 끝나면 서버를 종료합니다.

- HTTP 검사: `scripts/check-localized-pages.mjs`
- 렌더링 결과: `.test-output/pages` (버전 관리 제외)
- 번역 검사 결과: `.next/translation-coverage.json` (버전 관리 제외)
- 게임 규칙: `tests/new-mini-games.test.mjs`

렌더링 검사 파일은 실행 중인 Next.js 빌드 폴더에 저장하지 않습니다. 브라우저 화면 검사와 실제 계정으로 로그인한 후의 검사는 이 자동 검사에 포함되지 않습니다.
