# 단서공방 영어 스토리 학습 설계

작성일: 2026-10-14 (Asia/Seoul)

단서공방의 주력은 영어 교육 콘텐츠다. 방탈출·회화·추리·퍼즐·동화를 함께 즐기면서 읽기, 듣기, 쓰기, 말하기를 연습하는 하나의 패키지로 구성한다. 기존 게임은 별도의 게임 둘러보기 영역에서 이용한다. 이 문서는 새 콘텐츠의 학습 설계와 제작 기준을 기록한다. 연구가 제품 자체의 효과를 검증했다는 뜻은 아니다.

## 제품의 출발점

- 같은 이야기를 이용자가 고른 입문·기본·도전 난이도로 플레이한다. 난이도는 연령이나 공인 영어 등급이 아니라 도움의 양, 언어의 길이, 추론과 출력 요구의 차이다.
- 작은 해안 도시 여울을 첫 시즌의 공통 배경으로 사용한다. 사람들의 항구와 서점, 동물들의 달빛 우체국은 각 장르의 독립된 이야기다. 마법의 규칙은 동화 안에서 먼저 알려 주고 따른다.
- 주요 장면 그림, 일관된 타이포그래피, 단서 문서와 음성, 행동의 결과를 통해 완성도를 만든다. 기술의 복잡함보다 읽기 쉬운 장면과 설득력 있는 진행을 우선한다.
- 실시간 생성 없이 검토한 원고와 난이도별 변형을 사용한다. 문항의 선택지, 쓰기의 핵심 정보, 말하기 자기 확인은 학습 진행을 위한 장치다.
- 말하기는 소리 내어 표현하고 스스로 완료를 확인하는 연습이다. 발음·유창성을 자동 평가했다고 표시하지 않는다. 듣기는 우선 음성으로 듣고 원문과 번역은 필요할 때 확인한다.
- 월 2만~3만 원은 향후 검토할 구독 가격 범위다. 현재 콘텐츠 수와 결제 기능으로 그 가치를 이미 제공한다고 주장하지 않는다. 새 에피소드 수, 제공 주기, 음성 서비스 등 운영 가능한 범위를 확인하고 상품을 확정한다.

## 첫 번째 페이지: 원작 에피소드 3편

`lib/english/catalog.ts`에 3편 × 5단계 × 3난이도, 총 45개 과제 버전을 담았다. 각 편은 3개씩 총 9개의 독립적인 복습 표현을 갖는다. 한 난이도에서 경험하는 과제는 5개이며, 난이도 버전을 다른 에피소드 수로 계산하지 않는다.

| 에피소드          | 독립된 이야기의 목적과 인과                                                                                                                                                                                                   | 학습 순서                          | 대표 표현                                                                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------- |
| 닫힌 서점의 밤    | 정전으로 자동문 모터가 멈춘다. 직원은 밖의 쓰러진 간판을 치우고, 이용자는 위치와 도움 요청을 전달한다. 직원 확인 후 수동 해제로 문을 열고 지붕 있는 통로로 귀가한다. 초록색 비상문은 상시 이용 가능하다.                      | 읽기 → 쓰기 → 듣기 → 읽기 → 말하기 | Could you help me open the door? / What should I do next? / I'll take the covered walkway.    |
| 7번 보관함의 편지 | 봉사자는 직원이 허가한 업무용 보관함의 신고서를 읽는다. 비슷한 파란 가방 두 개 중 은색 별과 15:20 레몬빵 영수증이 일치하는 B를 찾는다. 직원이 미공개 내용물을 별도로 확인한 뒤 반환한다.                                      | 읽기 → 듣기 → 쓰기 → 읽기 → 말하기 | Could you describe your bag? / Could you check the receipt? / The receipt matches the letter. |
| 달빛 우체국       | 다음 날 해 질 무렵 축제를 위한 초대장을 오늘 밤 전달한다. 봉투의 이름과 목적지, 등불별 노선, 두 번째 종 출항, 해 뜨면 쉬는 운항 규칙을 처음에 제시한다. 흰 등불 배와 조개 표지 돌길로 등대에 가서 받는이를 확인하고 전달한다. | 읽기 → 듣기 → 쓰기 → 듣기 → 말하기 | Where should I deliver this letter? / When does the boat leave? / I have a letter for you.    |

첫 묶음은 길게 읽는 동화·긴 대화 역할극보다 짧은 통합형 미션에 초점을 두었다. 향후 장르별 작품은 읽기 중심 동화, 듣기 중심 증언 사건, 쓰기 중심 편지 퍼즐, 말하기 중심 회화 미션으로 확장해 각 작품의 강점을 유지한다. 올인원은 모든 작품의 기능이 같다는 의미가 아니라, 공통 계정·학습 흐름·복습으로 여러 종류의 연습을 이어 간다는 의미다.

## 난이도와 도움

| 모드 | 입력                                                     | 출력과 도움                                                                                 |
| ---- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 입문 | 짧고 직접적인 문장. 한 단서를 찾거나 한 동작을 이해한다. | 한 줄 요청이나 주소를 만든다. 문장 시작 힌트와 한국어 도움을 선택할 수 있다.                |
| 기본 | 짧은 문단. 위치·시간·품목처럼 여러 정보를 함께 비교한다. | 위치와 요청, 대상과 목적지처럼 두 개 이상의 핵심 정보를 전달한다.                           |
| 도전 | 긴 단서, 대비되는 설명, 이유와 다음 절차를 추론한다.     | 보기 없이 이유·조건·다음 행동을 포함해 작성하거나 말한다. 예문은 먼저 시도한 후 볼 수 있다. |

세 버전은 같은 사건의 사실을 유지한다. 인물 이름, 물건 특징, 시각, 목적지, 안전 장치가 난이도에 따라 바뀌지 않는다. 다른 언어 요구를 갖지만 학습자가 어떤 모드를 선택해도 이야기의 결말은 같다. 사용자의 변경 가능성을 유지하며 특정 연령이나 CEFR 수준으로 단정하지 않는다.

쓰기의 허용 문장과 키워드 묶음은 필요한 정보가 있는지 확인하는 간단한 연습 보조다. 의미가 맞는 새로운 표현을 완벽하게 인식할 수 없고, 문법이 틀린 문장에서도 키워드가 맞을 수 있다. 실패한 경우 필요한 정보와 참고 문장을 보여 주고 다시 작성할 수 있게 한다. 자연어 채점처럼 보이는 수치나 틀린 문법을 교정했다는 안내를 생성하지 않는다.

말하기는 자기 확인이다. 예문을 보고 따라 말한 것과 보기 없이 먼저 표현한 것은 모두 연습이지만 같은 수준의 수행 증거는 아니다. 진행 저장 시 자기 확인 기록을 사용하고 발음 정확도나 공인 능력 점수로 환산하지 않는다.

## 서사 검수 기준

각 원고를 공개하기 전에 다음을 사람의 눈으로 확인한다.

1. 주인공은 누구에게 무엇을 전달하거나 어떤 문제를 해결하려 하는가? 지금 행동해야 하는 이유가 앞부분에 제시됐는가?
2. 영어를 이해하거나 사용하는 행동이 실제 상황의 결과에 연결되는가? 임의의 문법 정답이 물리적 자물쇠를 여는 장면은 없는가?
3. 해결에 필요한 정보가 정답을 고르기 전에 주어졌는가? 결말에서 갑자기 새로운 단서를 꺼내 추리를 뒤집지 않는가?
4. 여러 자료의 시각, 색, 방향, 순서, 물건 수가 일치하는가? 입문에서도 공유된 피드백과 결말의 사실을 확인할 수 있는가?
5. 오답이 왜 맞지 않는지 해당 자료의 근거로 설명하는가? 근거 없이 '틀렸습니다'만 표시하지 않는가?
6. 방탈출은 안전 장치가 작동하는 일상적 사건으로 성립하는가? 추리에서는 학습자가 알 수 있는 단서와 직원만 확인하는 절차가 구분되는가?
7. 동화의 규칙은 사용 전에 설명되는가? 흰 등불 노선, 두 번째 종 출항, 일출 이후 휴항을 결말에서도 따르는가?
8. 목표를 달성한 뒤 인물의 반응과 후속 처리를 보여 주는가? 기록 조회나 버튼 클릭만으로 끝나지 않는가?

현재 세 편에서 분실물 직원은 미나(Mina)다. A 가방과 B 가방은 동일한 물건이 아니며, 은색 별·레몬빵·15:20은 B의 정보다. 서점의 정문과 초록 비상문은 별개의 출입구다. 동화의 흰 등불과 호박빛 등불은 서로 다른 배의 노선 표지다. 생성한 그림이 이 사실과 충돌하면 원고를 그림에 맞춰 억지로 바꾸지 말고 그림을 수정한다.

## 그래픽과 사용성 검수 기준

- 세 장르의 대표 그림은 서로 다른 공간을 보여 준다. 서점은 따뜻한 실내와 방문객, 분실물 안내소는 직원과 보관함, 동화는 달빛과 동물 우체국의 분위기를 갖는다. 대표 그림은 이야기의 공간을 소개하는 장면이며 사건의 모든 순간이나 단서를 표시하는 지도가 아니다.
- 그래픽은 장면의 분위기를 만들고, 정답에 필요한 정보는 접근 가능한 텍스트·음성 자료로 제공한다. 이미지 속 읽기 어려운 가짜 글자나 생성 오류를 핵심 단서로 쓰지 않는다.
- 단서용 번호·시각·색·방향은 HTML 문서의 검토한 값으로 표시한다. 색만으로 의미를 구분하지 않고 '흰 등불', '은색 별' 등 이름도 제공한다.
- 모바일과 데스크톱에서 주요 이미지의 잘림, 문서 줄바꿈, 버튼 대비, 긴 보기, 텍스트 입력, 완료 상태를 확인한다. 분위기 그림이 입력 영역을 밀어내거나 클릭을 가리지 않아야 한다.
- 듣기 원문과 번역은 기본적으로 접어 두고 음성 재생을 우선한다. 청각 접근성, 음성 미지원 환경에서는 텍스트로도 진행 가능하게 한다. 텍스트를 읽어서 푼 시도는 듣기 실력 측정으로 보고하지 않는다.
- 말하기 예문은 시도 전부터 강제로 펼치지 않는다. 자기 확인 버튼이 무엇을 기록하는지 분명히 쓴다. 마이크를 쓰지 않는 모드에서 녹음 권한을 요청하지 않는다.
- 배경 음악·효과음은 듣기 음성과 경쟁하지 않는다. 음량·끄기 조작을 제공하고 선택한 상태를 존중한다.
- 영어 조각, 정답 피드백, 번역, 다음 장면이 같은 카드에 과밀하게 쌓이지 않도록 한다. 이야기 읽기와 연습 행동의 시각적 흐름을 유지한다.

## 성장 기록과 향후 구독

학습 화면에는 완료한 에피소드, 네 기능별 연습 횟수, 저장한 표현, 복습할 표현, 활동 기록을 보여 준다. 게임 점수와 영어 능력은 별개다. 같은 과제를 반복 완료해 새 과제 수나 신규 보상을 계속 증가시키지 않는다. 난이도 변경과 재플레이는 가능하게 한다.

현재 3편과 9개 표현은 전체 구독제의 가치를 확인하기 위한 초기 패키지다. 향후 가격을 확정하기 전에는 다음을 점검한다.

- 장르별로 일정한 이야기·시각 품질을 유지하면서 새 작품을 공급할 수 있는 제작 시간과 비용.
- 처음과 비교해 새 상황에서도 뜻을 이해하고 요청·설명할 수 있는지, 며칠 뒤 보기를 가려도 표현을 회상하는지.
- 재방문, 복습 수행, 다른 장르 진입 같은 이용 기록과 학습 결과를 구분한 평가.
- 월별 이용권 범위와 무료 체험 범위, 음성 제공 방식과 비용, 실제 계정별 진도·결제·환불 처리.

운영 가능성을 확인하기 전에는 매주 신작, 무제한 회화, 완벽한 자동 평가, 전체 수준의 영어 향상을 약속하지 않는다. 월 2만~3만 원의 가치는 콘텐츠 숫자를 부풀리는 방식이 아니라 장르별 좋은 작품, 이어지는 학습 기록, 유용한 복습으로 검증한다.

## 구현 점검

- 카탈로그: `lib/english/catalog.ts`.
- 스키마: `lib/english/types.ts`.
- 에피소드 ID: `closed-bookshop`, `locker-seven`, `moonlight-post`.
- 각 에피소드에는 서로 다른 ID의 5개 과제와 3개 표현이 있다. 각 과제는 입문·기본·도전 버전 모두에 본문·번역·요청·참고 답안을 갖는다.
- 읽기·듣기 선택지는 각 버전에 정확히 하나의 정답 ID를 가진다. 쓰기 참고 답안은 허용 답안 목록에 포함된다. 모든 과제의 표현 ID는 실제 표현을 가리킨다.
- 카탈로그의 공개 답안은 학습 자료다. 서버 권한 검사, 계정별 진도 저장, 중복 보상 방지는 별도로 검증한다.
- 배포는 저장소의 AGENTS.md 절차를 따른다. 기존 비공개·삭제 요청 콘텐츠를 다시 노출하지 않는다.
