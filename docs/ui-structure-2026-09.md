# 사이트 구성 정리 · 2026-09-09

## 페이지별 역할

- 홈: 대표 작품, 미니 프로젝트, 교육 기록, 준비 중인 영어 수업팩을 간략히 소개한다.
- 작품: 작품별 표지·줄거리·인원·시간과 공식 펀딩 기록을 보여준다.
- 미니 프로젝트: 게임 종류별 목록과 개별 플레이 화면을 제공한다. 제목은 기존 이름을 유지한다.
- 활동 기록: 교육·펀딩·수상 이력을 날짜순으로 제공한다.
- 공방 소개: 팀의 시작, 입주·수상 근거, 제작 과정을 설명한다. 작품·교육 목록을 다시 펼치지 않는다.
- 교육: 파일럿 준비 상태를 먼저 밝히고, 수업팩 상세 안내와 학원 관리 체험을 제공한다.
- 수강생 자료실: 수업별 발표자료·실습 자료를 바로 찾게 한다. 활동 소개와 합치지 않는다.
- 문의: 이메일과 문의에 필요한 항목을 제공한다.

## 공통 UI

목록 페이지 6곳은 PageIntro를 공유한다. 제목, 설명 한 문장, 필요한 링크만 둔다. 제목·본문 폭·간격은 컴포넌트와 디자인 토큰에서 관리한다.

상단의 홈 링크는 로고와 중복되므로 데스크톱에서 생략한다. 모바일 메뉴에는 홈을 유지한다. 학원 관리 로그인은 교육 페이지·모바일 메뉴·푸터에서 제공한다.

푸터는 작품·공방 / 교육·자료 / 문의로 나눈다. 같은 링크를 두 그룹에 넣지 않는다. 메뉴의 모바일 전환과 펼침 영역은 같은 1200px 기준을 사용한다.

CSS는 기존 덧붙임 규칙을 정리했다. 공통 메뉴·버튼·푸터는 styles/site.css, 목록 제목은 page-intro.module.css, 교육 소개는 overview.module.css에서 관리한다. 사용하지 않는 과거 섹션의 스타일은 제거했다.

## 이번 변경에 포함하지 않는 작업

별도로 진행 중인 스피킹 연결, 브랜드 영상, 에피소드 예고편 변경은 유지하되 이번 배포 소스에는 넣지 않는다. 해당 작업의 환경변수·개인 자료·접근 권한도 변경하지 않는다.

## 확인 범위

배포 대상 소스만 별도 디렉터리에서 빌드하고 기존 테스트와 구성 회귀 테스트를 실행한다. 새 구성의 제목, 링크, 상태 표시, 중복 링크, 모바일 메뉴 기준을 검사한다. 브라우저 시각 검사는 이번 요청에 포함되지 않아 실행하지 않는다.
