## 적용 판단

- 모루의 고글, 빨간 목도리, 가죽 앞치마와 망치 영감의 흰 수염, 주황 머리띠를 기존 코드에서 확인해 일러스트에 반영했다.
- 전투 캐릭터는 무기·포즈·장비 변화에 맞춰 관절을 그린다. 전투 중 애니메이션은 유지하고, 큰 일러스트는 타이틀·이야기 장면에 사용했다.
- 이동 지형과 배경이 혼동되지 않도록 두 전투 배경의 채도를 낮추고 가까운 풀·나무 레이어를 겹쳤다.
- 일반 치명타는 기존 색상별 벡터 효과를 사용한다. 강한 벽 충돌에만 돌 파편 이미지를 사용한다. 그래픽 품질이 낮거나 화면 번쩍임을 껐을 때는 원래 타격 문양을 표시한다.
- 이미지 로드 전 또는 로드 실패 시 Canvas 그림을 사용한다. 이미지 객체는 재사용하며 매 프레임 새로 생성하지 않는다.
- 아이콘은 작은 크기에서 선명하게 표시되도록 SVG로 제작했다. [아이콘 폴더](../icons)의 진입·설정·안내서·모루는 타이틀에, 벽 세우기·벽꿍·파괴는 조작법에 적용했다.

## 검증

- `node tools/build.mjs`: 성공. `dist/assets`에 그림과 아이콘을 복사한다.
- `node tools/sim.mjs 180 1`: 180초 전투 시뮬레이션에서 실행 오류 없음. 한 판 전체를 완료했다는 뜻은 아니다.
- 브라우저: 타이틀, 이어하기 포함 메뉴, 조작법, 모루 도입부, 망치 영감 이야기 탭, 초원·숲 배경, 벽꿍 효과, 낮은 그래픽 품질을 확인했다.
- 개발 서버와 HTTP로 연 배포본에서 브라우저 오류 로그 없음. Electron 앱 패키징과 전 층 플레이 검증은 수행하지 않았다.
- 전신 2장과 이펙트 1장에 투명 알파 채널이 있다.

## 다시 확인하기

`game` 폴더에서 `python3 -m http.server 8766 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:8766/tools/art-review.html`을 연다. 검수 버튼은 실제 게임의 장면과 대화창을 호출한다. 전투 장면은 비교하기 쉽게 정지하며, 이펙트 버튼은 효과 한 프레임을 고정한다. 이 페이지는 테스트 저장을 쓰므로 평소 게임을 실행하는 포트와 다른 포트를 사용한다.

작업 전 소스 복사본은 `game/output/art-pass/before`에 있다. 다른 층의 배경과 다른 주민의 전신은 이번 제작 범위에 포함하지 않았다.

## 2026-09-24 추가 적용

- `hive-v1.png`, `cave-v1.png`, `rift-v1.png`: 이미지 생성 도구로 만든 벌집·동굴·관문 배경. 각 `.prompt.txt`에 생성 지시문을 보관했다.
- `src/ally_art.js`: 고든·카이·돌배·그을음·피리의 전투용 몸체를 Canvas로 그린다. 모루와 같은 관절과 장화 렌더러를 사용하며, 복장과 머리 장식은 동료별로 다르다. 조우·동행·쓰러짐 장면에 공통 적용된다.
- 동료 본체는 생성 PNG가 아니다. 이미지 생성 한도에 도달해 기존 Canvas 렌더링을 수정했다. 말랑 및 별도 몸체를 가진 추가 동료는 이번 교체 대상에서 제외했다.
- `tools/art-review.html`의 동료 비교에서 이동·공격 자세와 장비를 확인할 수 있다.
